# Quickstart: 007

1. Ver → Acercar contenido dos veces: el texto pasa a 110 %, la barra de estado muestra "Zoom 110 %", las pestañas no cambian.
2. Ctrl + rueda sobre el contenido: cambia de a 5 %; sobre la barra de pestañas no cambia nada.
3. Temas → "Ajuste tamaño de barra" a 150 %: crecen la barra de pestañas y la del editor; el contenido no.
4. Exportar a PDF con zoom 150 %: mismas páginas que a 100 %.
5. Pruebas: `tests/unit/themes-zoom.spec.ts`, `tests/e2e/ui/themes-zoom.spec.ts`, `tests/e2e/native/export-long.cdp.mjs`.
